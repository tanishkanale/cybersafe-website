🛡️ CyberSafe – Cybersecurity Awareness Website

Stay Alert. Stay Secure. Stay CyberSafe.

CyberSafe is a cybersecurity awareness website designed to help users understand common online threats and develop safer digital habits.

✨ Features

- Know the Threats – Learn about common cyber threats.
- Safety Tips – Discover ways to stay protected online.
- Cyber News – Stay informed about cybersecurity updates.
- Cybersecurity Quiz – Test your knowledge.
- Level 2 Quiz – Challenge yourself with advanced questions.

💻 Technologies Used

- HTML
- CSS
- JavaScript

🎯 Project Objective

To spread cybersecurity awareness and encourage safe internet practices through an interactive and educational platform.
